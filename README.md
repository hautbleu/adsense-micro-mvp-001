# AdSense Micro MVP 001

Pre-launch acquisition experiment using public NHTSA vehicle-safety datasets.

## Status
- 10 deterministic vehicle samples
- 30 vehicle reference pages plus support pages
- complaint counts deduplicate NHTSA ODINO
- recall counts deduplicate NHTSA campaign numbers
- pre-launch only: all pages remain noindex and robots.txt blocks crawling
- no advertising or analytics enabled

## Data notes
Consumer complaints are reports submitted to NHTSA and are not, by themselves, verified defects. Use the official NHTSA VIN lookup for vehicle-specific recall status.

Raw NHTSA bulk files and normalized local data are intentionally excluded from this repository.
