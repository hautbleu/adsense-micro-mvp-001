Vehicle Safety Reference Prototype

This research site tests whether public vehicle-safety records can be organized into useful reference pages without confusing consumer reports with verified defects.

How to read the data

Complaint totals deduplicate NHTSA ODINO reference numbers because one complaint may be classified under multiple components. Recall totals deduplicate campaign numbers. Use the official NHTSA VIN lookup for vehicle-specific recall status.
