Methodology and Data Sources

Complaint data comes from NHTSA bulk complaint files received during 2020–2026 in this prototype. Rows are tab-delimited. The same ODINO reference can appear once for each component classification, so unique complaint totals deduplicate by ODINO.

Recall data comes from the NHTSA post-2010 recall dataset. A campaign can contain multiple component rows, so recall totals deduplicate by campaign number.

Generated pages are checked against normalized JSON for complaint and recall count parity. Component frequencies may overlap and are not defect rates.

Data snapshots can change as NHTSA updates its source records. Vehicle-specific open recall status should be checked using the official NHTSA VIN service.

Prototype based on NHTSA public safety datasets. Not affiliated with NHTSA or vehicle manufacturers.
